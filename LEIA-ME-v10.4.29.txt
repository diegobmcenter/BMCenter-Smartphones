BMCenter Smartphones v10.4.29

CORREÇÃO DO BUILD NA VERCEL

Problema:
- No computador, o BAT instalava as dependências com --legacy-peer-deps.
- Na Vercel, o comando era npm install sem essa opção.
- A Vercel parava em "Command npm install exited with 1".

Correção:
- Criado arquivo .npmrc com legacy-peer-deps=true.
- vercel.json agora força:
  npm install --legacy-peer-deps
- Mantidas as dependências da IA local da v10.4.28.
- O BAT continua testando npm run build antes do push.

Publicação:
1. Extraia este ZIP em uma pasta nova.
2. Execute PUBLICAR-ATUALIZACAO.bat.
3. Aguarde BUILD APROVADO.
4. O BAT envia a v10.4.29 ao GitHub.
5. A Vercel deverá instalar com --legacy-peer-deps e então executar o build.
