BMCenter Smartphones v10.4.38 — PHOTO STUDIO V2

Esta versão NÃO usa o recorte antigo das v10.4.33–v10.4.37.

ARQUITETURA
- @mediapipe/tasks-vision 1.0.1, mesma geração usada no sample Web atual do Google.
- Interactive Segmenter V2 / MagicTouch int8.
- Execução dentro de Web Worker para não travar a interface.
- API atual: setImage() + segment(strokes).
- Suporta múltiplos traços POSITIVOS e NEGATIVOS.

REGRA PRINCIPAL
A IA só produz a máscara.
O smartphone/objetos preservados são copiados pixel a pixel da foto ORIGINAL.
Nenhuma IA generativa redesenha aparelho, câmeras, tela, riscos ou proporções.

RECORTE
- Automático: começa com um traço positivo central.
- Ajustar recorte: botão de mira em cada foto.
- Verde / Preservar: passe o dedo sobre qualquer parte que precisa continuar na foto
  (inclusive mão/dedos caso estejam segurando o aparelho).
- Vermelho / Remover fundo: passe sobre partes do fundo que entraram no recorte.
- É possível usar vários traços.
- Buracos internos da máscara são fechados para proteger tela, câmeras e reflexos.
- A borda só é expandida para fora; nunca é erodida para dentro.

CENÁRIOS
Há atalhos visuais para Branco Clean, Cinza Premium, Preto Premium, Madeira Clara,
Concreto Claro, Mármore Branco, Azul Tech e Bege Minimalista, além da biblioteca
completa já existente.

TESTE RECOMENDADO
1. Use uma foto.
2. Clique Preparar todas.
3. Se algo estiver faltando, clique no botão de mira da foto.
4. Em + Preservar, risque sobre a área faltando (telefone, mão, dedo).
5. Se houver fundo sobrando, use - Remover fundo sobre aquela área.
6. Clique Aplicar recorte e cenário.
7. Compare Original x Preparada.

O critério de aprovação é: aparelho na mesma posição, tamanho, perspectiva e detalhes;
somente o fundo deve mudar.
